# Trady

백엔드 시스템의 성능, 동시성, 데이터 정합성 및 장애 대응을 학습하고 검증하기 위한 모의 주식 거래 시스템입니다. 


## 구현 목표

핵심 비즈니스 로직의 정확한 구현과 기술적 문제의 분석 및 개선에 집중하는 것이 목표이다.

| 기능 | 주요 내용 |
| --- | --- |
| 주식 차트 | 키움 REST API 기반 데이터 수집, 종목·기간별 OHLCV 조회 |
| 주문 및 체결 | 지정가·시장가 주문, 가격·시간 우선 매칭, 부분 체결 |
| D+2 결제 | 결제 예정 데이터 관리, 배치 처리, 실패 재처리 및 중복 반영 방지 |
| 계좌 현황 | 현금, 주문가능금액, 보유종목, 평가손익 및 결제 예정 금액 조회 |


## 기술 구성

- 백엔드: Java 17, Spring Boot
- 데이터베이스: PostgreSQL
- 프론트엔드: React
- 외부 연동: 키움 REST API
