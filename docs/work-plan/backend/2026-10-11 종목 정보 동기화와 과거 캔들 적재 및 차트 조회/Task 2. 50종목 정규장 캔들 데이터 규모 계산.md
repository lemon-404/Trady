# 50종목 정규장 캔들 데이터 규모 계산

- 작성 날짜: 2026-10-12
- 계산 대상: 50종목의 정규장 1분·5분·15분봉 1년치 데이터와 페이지 수

## 1. 확인 목적

Task 3의 DB 기반 차트 조회 API가 다룰 데이터 규모를 예상한다. 초기 제공 범위를 50종목·1년·1분/5분/15분봉으로 두고, 정규장 캔들만 적재하는 경우의 건수와 900개 단위 페이지 수를 계산한다.

## 3. 계산 방법

| 기준 | 값 |
|---|---|
| 제공 종목 | 50개 |
| 과거 기간 | 1년 |
| 연간 거래일 | 250일 가정 |
| 정규장 | 09:00~15:30, 하루 390분 |
| 봉 주기 | 1분·5분·15분 |
| 페이지 크기 | 900개 |

~~~text
종목당 하루 캔들 수 = 390분 ÷ 봉 주기
종목당 1년 캔들 수 = 하루 캔들 수 × 250거래일
50종목 캔들 수 = 종목당 1년 캔들 수 × 50
종목당 페이지 수 = 올림(종목당 1년 캔들 수 ÷ 900)
50종목 페이지 수 = 종목당 페이지 수 × 50
~~~

250거래일은 규모 계산용 가정이며, 특정 연도의 실제 거래일 수를 확인한 값은 아니다. 각 시간 구간에 봉이 존재한다는 단순 모델을 사용하므로 체결 없는 구간, 거래정지, 봉 경계 처리 등에 따라 실제 적재 건수는 달라질 수 있다.

## 4. 계산 결과

### 1. 캔들 데이터 수

| 봉 주기 | 종목당 하루 | 종목당 1년 | 50종목 1년 |
|---|---:|---:|---:|
| 1분봉 | 390개 | 97,500개 | 4,875,000개 |
| 5분봉 | 78개 | 19,500개 | 975,000개 |
| 15분봉 | 26개 | 6,500개 | 325,000개 |
| 합계 | 494개 | 123,500개 | **6,175,000개** |

50종목의 정규장 1분·5분·15분봉을 1년치 보관하는 초기 데이터 규모는 약 617만 건으로 예상한다. 실제 적재 후 봉 주기별 건수와 조회 성능을 측정할 때 이 값을 비교 기준으로 사용한다. 이 계산은 실제 데이터 적재나 조회 성능 검증을 완료했다는 의미가 아니다.

### 2. 페이지당 900개 기준 페이지 수

| 봉 주기 | 종목당 1년 | 종목당 페이지 | 50종목 페이지 |
|---|---:|---:|---:|
| 1분봉 | 97,500개 | 109페이지 | 5,450페이지 |
| 5분봉 | 19,500개 | 22페이지 | 1,100페이지 |
| 15분봉 | 6,500개 | 8페이지 | 400페이지 |
| 합계 | 123,500개 | 139페이지 | **6,950페이지** |

페이지는 종목·봉 주기마다 따로 조회하므로 각각 올림한 뒤 50배한다. 마지막 페이지의 남는 공간을 다른 종목이나 봉 주기의 데이터로 채울 수 있다고 계산하지 않는다.

이 페이지 수는 정규장 캔들만 한 페이지에 900개씩 받는다는 가정의 환산값이다. 실제 ka10080 응답에 애프터마켓 데이터가 함께 포함된다면 정규장 데이터만 DB에 적재해도 그 데이터를 받기 위한 요청 페이지 수는 더 많아질 수 있다. 실제 요청 횟수는 적재 실행 시 별도로 기록한다.
