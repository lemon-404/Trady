# Trady 폴더 구조

Trady 프로젝트의 폴더 구조와 각 폴더의 역할을 설명한다.

~~~text
Trady/
├─ .agents/
│  └─ skills/
├─ backend/
├─ docs/
│  ├─ 폴더 구조.md
│  ├─ 01_planning/
│  ├─ 02_architecture/
│  ├─ 03_api/
│  ├─ 04_database/
│  ├─ 09_schedule/
│  ├─ superpowers/
│  │  └─ plans/
│  └─ work-plan/
│     └─ backend/
│        ├─ 2026-10-10 키움 API 토큰 관리 구조.md
│        └─ 2026-10-10 키움 API 토큰 관리 구조/
│           └─ 토큰 발급 갱신 폐기 정책 검증.md
├─ frontend/
└─ AGENTS.md
~~~

| 폴더 명 | 폴더 설명 |
|---|---|
| `.agents/` | 프로젝트 전용 에이전트 스킬 저장 |
| `.agents/skills/` | 에이전트 스킬을 저장|
| `backend/` | Spring Boot 백엔드 코드 |
| `frontend/` | React 프론트엔드 코드 |
| `docs/` | 프로젝트 기획·설계·작업 문서 |
| `docs/01_planning/` | 프로젝트 목적·기능·구현 범위 |
| `docs/02_architecture/` | 시스템 구조와 구성 요소의 관계 |
| `docs/03_api/` | API 설계와 외부 API 참고 자료 |
| `docs/04_database/` | 데이터베이스 구조·테이블·SQL |
| `docs/09_schedule/` | 개발 일정과 단계별 구현 범위 |
| `docs/superpowers/plans/` | writing-plans가 작성하는 구현 순서·수정 파일·검증 절차 |
| `docs/work-plan/` | work-plan이 작성하는 작업 목적·설계 근거·예정 작업 |
| `docs/work-plan/{작업 영역}` | 작업 영역별 목적·설계·구현 계획 |
| `docs/work-plan/{작업 영역}/{작업 계획 파일명}` | 해당 작업의 수행 과정과 수행 결과 |
| `AGENTS.md` | 에이전트가 따를 작업 범위·개발 원칙·워크플로우 |
