
# 프론트엔드 프로젝트 기능 및 구현 범위 v1

## 1. 사용자

본 프로젝트의 핵심은 사용자 관리가 아닌 주식 거래 백엔드 시스템 구현에 있으므로 복잡한 회원 기능을 구현하지 않는다.

성능 및 동시성 테스트에서는 테스트용 사용자와 계좌 데이터를 생성하여 사용한다.

프로젝트 진행에 필요한 최소한의 사용자 식별 기능만 구현한다.

---

## 2. 프론트엔드

프론트엔드는 백엔드 기능을 직접 확인하고 테스트할 수 있는 최소한의 UI만 구현한다.

기본적으로 다음 화면만 제공한다.

- 차트 조회 화면
- 주문 화면
- 계좌 현황 화면

D+2 결제는 별도의 복잡한 사용자 화면을 구현하지 않고 계좌 현황에서 결제 예정 정보를 확인할 수 있도록 한다.

디자인 시스템 구축, 애니메이션, 반응형 UI 고도화 등 프론트엔드 완성도를 높이기 위한 작업은 프로젝트의 주요 범위에 포함하지 않는다.
