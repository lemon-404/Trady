# 배경 및 기대효과

## 1. 배경

단순하게 반복문을 통해 임의로 데이터를 생성하여 대규모 데이터 처리와 성능 최적화를 학습하기보다는, 실제 서비스와 유사한 환경에서 발생하는 기술적 문제를 직접 경험하고 해결하고 싶었다.

주식 시장은 종목별 가격과 거래량이 시간에 따라 지속적으로 기록되므로 대규모 시계열 데이터를 확보하고 활용하기에 적합하다. 또한 주식 거래 시스템은 실시간으로 변화하는 시장 데이터와 동시다발적인 주문을 처리해야 하며, 거래 과정에서 데이터 정합성과 처리 순서를 보장하고 장애 발생 시에도 거래 상태를 안전하게 복구해야 한다. 특히 외부 거래소 및 시장 데이터 제공 시스템과 밀접하게 연결되어 있어, 외부 시스템의 지연이나 장애가 내부 서비스에 미치는 영향까지 고려해야 한다.

이러한 특성은 DB 성능, 서버 병목 및 지연, 동시성 제어, 데이터 정합성, 장애 대응 및 복구뿐만 아니라 외부 시스템 연동과 의존성 관리 등 백엔드의 핵심 기술적 문제를 하나의 시스템에서 경험할 수 있는 환경을 제공한다. 따라서 실제 서비스에서 발생할 수 있는 문제의 필요성과 해결 과정을 체감하며 백엔드 역량을 발전시키기 위해 모의 주식 거래 프로젝트 Trady를 선정하였다.

## 2. 기대효과

| 핵심 역량 | 기대효과 |
|---|---|
| 대규모 데이터 처리 및 DB 성능 최적화 | 대규모 시계열 데이터의 저장·조회 성능을 측정하고 병목을 분석·개선하는 역량 |
| 서버 성능 및 병목 분석 | 동시 요청 증가에 따른 처리량, 응답 지연, 자원 사용량을 분석하고 개선하는 역량 |
| 동시성 제어 | 동시다발적인 주문 환경에서 Race Condition을 방지하고 안정적으로 처리하는 역량 |
| 데이터 정합성 | 주문·체결·결제·계좌 전반의 데이터 일관성을 유지하고 검증하는 역량 |
| 장애 대응 및 복구 | 처리 중 발생하는 장애, 실패, 재시도 상황에서 중복·누락 없이 복구하는 역량 |
| 외부 시스템 연동 및 의존성 관리 | 실시간 외부 데이터를 안정적으로 처리하고 외부 시스템의 지연·장애에 대응하는 역량 |
