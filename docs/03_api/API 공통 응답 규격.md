# API 공통 응답 규격

## 1. 응답 원칙

- 응답 본문은 JSON 형식을 사용한다.
- `code`는 문자열로 반환한다.
- 성공 응답에는 `data`, 오류 응답에는 `errors`를 포함한다.
- 반환 데이터가 없으면 `data`는 `null`로 반환한다.
- `errors`는 배열로 반환하며, 필드를 특정할 수 없으면 `field`는 `null`로 반환한다.
- 템플릿의 `...`은 추가 항목을 의미하며 실제 응답에는 포함하지 않는다.

## 2. 응답 코드

| code | 의미 | 상태 |
|---|---|---|
| `"0"` | 요청 처리 성공 | OK |
| `"400"` | 잘못된 요청값 | BAD REQUEST |

## 3. 성공 응답 템플릿

```jsonc
{
  "code": "0",
  "message": "{{성공 메시지}}",
  "data": {
    "{{필드명}}": "{{값}}",
    ...
  }
}
```

## 4. 오류 응답 템플릿

```jsonc
{
  "code": "400",
  "message": "{{오류 메시지}}",
  "errors": [
    {
      "field": "{{오류 필드명 또는 null}}",
      "message": "{{필드 오류 메시지}}"
    },
    ...
  ]
}
```
